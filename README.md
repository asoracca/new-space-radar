# New Space Radar

Source-aware event research for RKLB, ASTS and LUNR: calendar alignment,
market-model abnormal returns, a provenance database and a small TypeScript
evidence explorer. **Descriptive event effects are separate from executable
signal evaluation. Neither z-scores nor low market correlation are catalyst
probabilities.**

## Run the saved demo

Python 3.12 is the validated runtime. No keys, paid data or provider calls are
needed. Initial dependency installation requires package access; calculations,
tests and the browser use local fixtures only.

```sh
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements-offline.lock
python main.py
python -m http.server 8976 --bind 127.0.0.1
# Open http://127.0.0.1:8976/explorer/
```

The explorer defaults to the saved **historical catalog**. Select LUNR's IM-1
landing to see `2024-02-22 18:23 EST → 2024-02-23`. The NASA source verifies the
occurrence time, not the first public announcement time. Historical returns are
not bundled: this event is excluded from CAR estimation. The other 17 original
records remain unverified rather than receiving invented sources or times.

Switch the input selector to **Synthetic validation** to inspect the shock and
control, their aligned curves, observation counts, sources and limitations.
Compiled browser assets are committed; Node is unnecessary to run the demo.

## Method and architecture

- `src/events.py`: validated event records and the single estimation/alignment
  engine. An offset-aware timestamp and IANA time zone map to the first XNYS
  regular session whose close is strictly later. At/after close, weekends and
  holidays move forward; early closes and daylight saving are respected.
- `fixtures/`: original catalog preserved verbatim, sourced annotations and
  frozen 2022–2025 XNYS schedule from `exchange-calendars==4.11.1`.
  Synthetic inputs are generated by the seeded model in `src/demo.py`.
- `src/car_curve.py`: uses the same engine. CAR sums log abnormal returns from
  the start of the event window. Across-event ranges are descriptive, not CIs.
- `src/store.py`, `migrations/`: immutable catalog records, source provenance,
  content-addressed runs and per-session outputs in local SQLite. Foreign keys,
  natural-key constraints and migration checksums protect the evidence.
- `src/export.py` → `evidence/results.json` → `explorer/`: exports reconciled
  SQLite results; TypeScript only filters and presents them, never estimates ARs.
- `src/backtest.py`: signals observed after close fill at the **next session
  close**, with explicit round-trip costs and same-symbol overlap suppression.
  It reports trade observations and a same-period SPY baseline, not portfolio equity.

Every estimation window ends before the event window and its gap. A required
stock/benchmark observation missing from either window excludes the event;
rows are never dropped to shift an event to an available price. Insufficient
history, duplicate announcements, overlapping same-stock event windows,
contaminated estimation windows and invalid model rank have explicit outcomes.

## Validate or rebuild

```sh
python scripts/check_offline.py
python -m src.export --out /tmp/space-evidence --db /tmp/space-evidence.sqlite
# Optional: regenerate the frozen calendar and review its diff
python scripts/freeze_calendar.py
# Optional: edit and rebuild the TypeScript browser (Node 22+, pnpm 10+)
cd explorer
pnpm install --frozen-lockfile
pnpm build
pnpm test
```

CI installs pinned dependencies, then runs tests, exports, TypeScript compilation
and browser-model tests in a **network-disabled Linux namespace**. Python tests
also block sockets. Bootstrap (checkout/runtime/package downloads) requires
network; the validation payload runs entirely offline. No provider data is used.

The older live charts/scanner remain opt-in: install `requirements.txt` and use
`python main.py --live` or `python main.py --signal`. Their provider availability,
data revisions and current outputs are outside the frozen validation. Archived
figures and journals are retained as historical project material, not validated
performance evidence.
